**下载：点下面「Assets」里的 LiteCast.apk**，这就是要装到电视上的文件。「Source code (zip)」「Source code (tar.gz)」是源代码，不用下载。

不知道怎么装？看 [安装方法](https://github.com/Jaqennn/LiteCast#安装)：U 盘、让 AI 帮你装、电脑 adb，三种任选一种。已经装了 0.2.0 的，直接装这个就会覆盖升级，设置都保留。

## 这一版

- 主页右上角新增「反馈」：电视上显示问卷二维码，旁边自动写好这台电视的品牌、型号、安卓版本和轻投版本，用手机扫码照着填就行，不用登录，国内网络能直接打开
- 设置里也能找到「反馈问题」；投屏失败时，提示下面会告诉你去哪里反馈

## 支持

- 电视：Android 5.0 及以上，ARM 芯片（市面上的安卓电视、盒子、投影仪几乎都是）
- 苹果手机、iPad、Mac：屏幕镜像、AirPlay 视频和音乐
- 安卓手机：视频 App 里的投屏按钮（DLNA）
