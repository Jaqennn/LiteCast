**下载：点下面「Assets」里的 LiteCast.apk**，这就是要装到电视上的文件。「Source code (zip)」「Source code (tar.gz)」是源代码，不用下载。

不知道怎么装？看 [安装方法](https://github.com/Jaqennn/LiteCast#安装)：U 盘、让 AI 帮你装、电脑 adb，三种任选一种。

## 轻投能做什么

- 免费、没有广告，不用登录，不限时长
- 苹果手机、iPad、Mac：屏幕镜像、AirPlay 视频和音乐
- 安卓手机：视频 App 里的投屏按钮（DLNA），B 站、爱奇艺、腾讯视频等都行
- 老电视也能用：Android 5.0 及以上，ARM 芯片（市面上的安卓电视、盒子、投影仪几乎都是）
- 能和电视自带的乐播同时开着，手机几秒内就能搜到轻投
- 开机自动在后台待命，手机一投，画面自己弹出来；投完自己关掉

## 反馈

主页右上角点「反馈」：电视上会显示问卷二维码，旁边写好这台电视的品牌、型号和安卓版本，手机扫码照着填就行，不用登录，国内网络能直接打开。能用、不能用都欢迎反馈，会整理进机型表。
