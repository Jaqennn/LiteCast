# 轻投 0.2.2-beta.1

本版本用于 Android 5.x 兼容性验证，天猫魔屏与乐视原设备的验证结果仍待收集。

- AirPlay 的 OpenSSL 改为静态链接并隐藏加密符号，避免旧系统加载同名 `libcrypto.so`。
- AirPlay 启动失败时保存具体错误，DLNA 独立启动和维护生命周期。
- 新增可用遥控器翻页、手机拍照的故障记录页面，包含设备与版本信息、错误编号和日志。
- 捕获到的退出错误在下次启动时展示；底层启动中断时保留最后阶段，不推测具体原因。
- 增加 APK 原生依赖检查和 Android 5.0、5.1、6.0、12 的模拟器验证流程。

问题反馈方法见 [故障记录说明](../diagnostics.md)。原有小米电视测试分支保持独立，尚未合并到本版本。
