**下载：点下面「Assets」里的 LiteCast.apk**，这就是要装到电视上的文件。「Source code (zip)」「Source code (tar.gz)」是源代码，不用下载。

不知道怎么装？看 [安装方法](https://github.com/Jaqennn/LiteCast#安装)：U 盘、让 AI 帮你装、电脑 adb，三种任选一种。

## 这一版

- 支持更老的电视：最低从 Android 6.0 降到 Android 5.0（5.x 还没有真机实测，欢迎反馈）
- 装了乐播的电视上，手机列表更快出现轻投：从最多约 20 秒缩短到几秒
- 说明重写：能投什么、支持哪些电视、下载哪个文件、怎么安装、怎么恢复原样
- 新增给 AI 的安装说明（[docs/agent.md](https://github.com/Jaqennn/LiteCast/blob/main/docs/agent.md)），会用 AI 的用户可以让 AI 一步步装好并验收

## 支持

- 电视：Android 5.0 及以上，ARM 芯片（市面上的安卓电视、盒子、投影仪几乎都是）
- 苹果手机、iPad、Mac：屏幕镜像、AirPlay 视频和音乐
- 安卓手机：视频 App 里的投屏按钮（DLNA）

能用或不能用，都欢迎 [反馈你的电视型号](https://github.com/Jaqennn/LiteCast/issues/new?template=device.yml)。
