# 轻投 0.2.4

**[下载 LiteCast.apk](https://github.com/Jaqennn/LiteCast/releases/download/v0.2.4/LiteCast.apk)**

沿用原正式签名，版本号 10，可覆盖 0.2.2、0.2.3 及此前正式版和测试版，保留设置。支持 Android 5.0 及以上，包含 ARM32 与 ARM64。

## 名称与改名修复

- AirPlay 和 DLNA 的默认名称统一为「轻投」，去掉电视品牌、型号和系统设备名的前缀。
- 升级启动时，将可识别的旧默认名称迁移为「轻投」，保留已有的自定义名称、开机自启和接收开关等设置。首次迁移后，自定义名称不会再被自动覆盖。
- 改名弹窗支持输入法「完成」直接保存；遥控器向下可从输入框移动到「保存」，按钮获得焦点时有明确边框。
- 新增「恢复为轻投」，直接保存默认名称；空白名称禁止保存。

旧版本未记录名称来源。若电视系统设备名曾变化、旧名称无法识别，可在主页「改名」中选择「恢复为轻投」。手机可能短暂缓存旧的设备名，重新打开投屏列表后查看。

## 验证与已知问题

新增旧默认名升级迁移、自定义名称保留、输入法完成保存、遥控器移动与保存、空白输入及恢复默认的回归检查。发布要求单元测试、Lint、原生检查及 Android 5.0、5.1、6.0、12 兼容性检查通过，并验证正式签名。

包含 0.2.3 的二维码移除与 AirPlay 修复。部分旧设备进度跳转后声音恢复较慢、DLNA 直接切换镜像时冻结仍待跟进。
