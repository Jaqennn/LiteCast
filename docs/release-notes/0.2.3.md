# 轻投 0.2.3

**[下载 LiteCast.apk](https://github.com/Jaqennn/LiteCast/releases/download/v0.2.3/LiteCast.apk)**，无需登录 GitHub。

本版使用原正式签名，版本号提高到 9，可直接覆盖 0.2.2、0.2.3-beta.1 或 beta.2，保留原有设置。支持 Android 5.0 及以上，包含 ARM32 与 ARM64。

## 更新内容

- 反馈页删除腾讯问卷二维码和扫码指引，保留电视品牌、型号、Android 版本、轻投版本及故障记录。打开反馈页时默认选中「故障记录」，可拍照后提交 GitHub Issue 或在社媒私信作者。同步清理首页和 Issue 模板中的问卷入口。
- 修复 AirPlay 原生线程退出与会话释放顺序，完善初始化失败后的清理，补齐设备信息请求需要的广播数据，改善旧系统连接闪退。
- Android 5.0/5.1 自动使用内置软件音频解码，避开部分旧电视系统音频解码器创建失败的路径。
- 切换视频和音频格式时清理旧解码状态与排队声音，保留清空边界之后的新声音，减少上一条视频声音残留。
- 视频解码器启动失败时自动重试，断开连接、分辨率变化或新会话会取消旧重试；释放过程报错时继续完成资源清理。
- 故障记录增加 AirPlay 连接阶段、音频解码路径、缓冲与解码统计，支持下次启动后查看。记录保存在本机，不包含播放地址、媒体内容或配对密钥。

## 验证与已知问题

发布前要求单元测试、Lint、原生线程与音频缓冲回归，以及 Android 5.0、5.1、6.0、12 模拟器检查通过。发布包检查原生依赖与原正式签名。

天猫魔屏测试反馈显示，beta.2 自动启用软件音频解码后未再闪退，抖音切换视频时旧声音残留已缩短。以下问题仍保留跟进：

- 部分旧设备拖动进度后，声音恢复较慢或音画不同步。手动 40 毫秒音频缓冲在该机型上出现断续，继续保留现有自动缓冲默认设置。
- 部分设备从 DLNA 直接切换到屏幕镜像时可能画面冻结，可结束当前投屏后重新连接。

小米电视专项后台发现方案仍处于独立测试分支，本版未合入。实际兼容性以具体电视和发送端的测试结果为准。
