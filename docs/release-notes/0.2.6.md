# 轻投 0.2.6

**[下载 LiteCast.apk](https://github.com/Jaqennn/LiteCast/releases/download/v0.2.6/LiteCast.apk)**

沿用原正式签名，版本号 12，可直接覆盖 0.2.0–0.2.5 及此前正式版，保留所有设置。支持 Android 5.0 及以上，包含 ARM32 与 ARM64。

本次更新完成全量代码审计与系统性稳定性修复，重点解决底层内存安全、死锁/ANR、AirPlay 与 DLNA 投屏竞态、画面异常及安全防护问题：

## Native / UxPlay 底层修复

- **音频时间轴缓冲（`timeline_buffer.h`）**：修复 `DelayTracker::observe()` 在大时钟跳变时 32 位有符号截断导致的负偏移越界写，并修复 Underrun 掩盖 `reanchor()` 的问题；将 `SpscRing` 与 flush 边界计数器升级为 `uint64_t`，避免 32 位 ARM 电视累计播放约 13.5 小时后的回绕错乱。
- **关闭防卡死与死锁修复（`android_raop_callbacks.c` / `audio_output.h`）**：`_video_wait_ready()` 改用 `CLOCK_MONOTONIC` 并在 `nativeStop()` 主动唤醒，消除关闭服务时的 10 秒主线程 ANR；`AudioOutput::stop()` 释放锁后再关闭 Oboe 流，消除与错误回调线程的 AB-BA 死锁，并校验出错流指针防止旧流回调误杀新流。
- **解码器与 JNI 健壮性（`audio_decoder.h` / `log_sink.h` / `android_dnssd_shim.c`）**：为 `LatencyProbe` 加上界限防止队列覆写竞争与 CPU 空转；修复 FFmpeg 浮点转 PCM 截断；统一补齐 JNI 判空、异常清理、安全 UTF-8 字符串构造与 UTF-8 字符边界截断；音频轨迹写入改用 `trylock` 避免受 `fsync()` 阻塞。
- **UxPlay 补丁 `0010`**：Live HLS 刷新改用单调时钟并增加超时恢复，修复单次刷新失败后直播永久停播的问题；无 `uuid` 的 `/play` 改按 URL 区分，修复连续投第二个视频时重播第一个视频的问题；拦截长度为 0 的 PIN proof 避免未定义行为。

## DLNA 与网络层修复

- **HTTP / SOAP / GENA 服务端（`HttpServer.java` / `Xml.java`）**：修复分块传输有符号整数溢出导致的远程 OOM 崩溃与无界 Trailer；限制 XML 最大嵌套深度防止远程栈溢出；剔除非法 XML 1.0 控制字符；修复 GENA 订阅竞态（避免新订阅在客户端收到 `SID` 前被误删）、`Expect: 100-continue` 与 `HEAD` 404 响应体问题。
- **格式嗅探与状态机（`MediaProbe.java` / `AvTransport.kt` / `DlnaRenderer.kt` / `SsdpServer.java`）**：调整 `MediaProbe.inspect()` 优先识别二进制容器魔数，修复合法 60 字节 `ftyp` MP4 与 fMP4 被误判为 XML/JSON 而中止播放的问题；为 `AvTransport` 引入 `loadId` 代际校验与 `autoPlayArmed` 锁内状态，消除切集永久失同步与已停视频被自动拉起的问题；修复 `Play(Speed="1")` 无法恢复 `1.0x` 倍速、多 `<res>` 元数据误取缩略图 MIME、土耳其语等 Locale 下的 `Seek` 失败及回环地址拦截；修复无网络启动永久卡在「启动中」与 1900 端口被占时的 Socket 句柄泄漏。
- **局域网代理绕过（`LanProxyBypass.kt`）**：完善完整 IPv6 字面量解析（支持展开形式回环 `0:0:0:0:0:0:0:1`、`::` 与十六进制 IPv4 映射地址）。

## AirPlayService、TV UI 与故障记录

- **配对码与音乐进度**：在断开连接、AirPlay 视频、DLNA 接管及关闭服务时清除 `_lastPin`，修复开启配对码后 `PlayerActivity` 永久卡死在 PIN 页面；修复暂停 AirPlay 音乐时进度条瞬间回跳 `00:00` 的问题。
- **AirPlay / DLNA 互斥与线程安全**：串行化视频播放/停止回调至主线程，`_connectionCount` 改用原子更新；修复旧 AirPlay 视频端误控 DLNA、DLNA 失败延迟定时器误杀新 AirPlay 视频、AirPlay 音乐与 DLNA 视频混播、抢占镜像时误关 `MediaSession`；修复固定音量电视（`getStreamMaxVolume == 0`）除零崩溃。
- **故障记录与系统权限（`Diagnostics.kt` / `HomeActivity.kt` / `BootReceiver.kt`）**：调整启动检查顺序，确保 Native 启动崩溃的面包屑轨迹追加保留而不被覆写删除；修复 Android 17+ 本地网络权限弹窗竞态与 Android 12+ 后台粘性重启误弹故障诊断页的问题。

## 音视频渲染器与设备发现

- **屏幕镜像渲染（`VideoRenderer.kt` / `VideoPipeline.kt` / `EglCore.kt` / `DecoderSelector.kt`）**：修复 `drainOutput()` 遇 `INFO_OUTPUT_FORMAT_CHANGED` 提前退出导致静态首帧黑屏的问题；增加 PTS 时钟跳变重锚与软解回退修复；补齐无显示 Surface 时的纹理变换矩阵（修复首帧倒置/未裁剪），同步等待 `surfaceDestroyed` 解绑并完善 `EglCore` 初始化校验与黑名单软解过滤。
- **视频播放器与 DACP / 发现（`AirPlayVideoPlayer.kt` / `DacpController.kt` / `DacpPlayer.kt` / `DmapParser.kt` / `NsdServiceManager.kt` / `UsbMdnsAdvertiser.kt`）**：直播流改用 `C.TIME_UNSET` 起播避免落到 DVR 窗口最旧位置；`clearSurface()` 在主线程同步执行；修复 IPv6 DACP 控制 URL 缺少方括号、跨会话串台与连接泄漏；限制 `DmapParser` 嵌套递归深度；兼容无 Wi-Fi 纯有线电视并修复 USB mDNS 拔线后无法重连。
