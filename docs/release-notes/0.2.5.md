# 轻投 0.2.5

**[下载 LiteCast.apk](https://github.com/Jaqennn/LiteCast/releases/download/v0.2.5/LiteCast.apk)**

沿用原正式签名，版本号 11，可直接覆盖 0.2.2、0.2.3、0.2.4 及此前正式版，保留设置。支持 Android 5.0 及以上，包含 ARM32 与 ARM64。

## 修复播放器生命周期崩溃

索尼 BRAVIA 4K VH2 / Android 12 的 0.2.2 故障记录显示 Java 空指针，混淆栈顶为 `c71.u` 第 576 行。检查原发布 APK 的 DEX 后，确认该位置为播放器进入视频界面前对空服务对象执行的强制取值。

服务解绑时，界面可能短暂保留旧的播放状态；待机、恢复、界面切换等生命周期变化可能经过这一路径。本版修复：

- 服务断开时，界面立即使用默认状态；更换服务或状态流时，首帧使用新来源的值。
- 每个接收服务实例拥有独立的播放器界面状态，重新绑定时重建该状态。
- 视频、镜像、音乐界面均要求服务对象存在，移除相关强制空值解引用。

## 故障记录行为

- 补充底层阶段信息时保留原崩溃的编号与时间，已查看、已选择重试的状态继续有效。
- 普通的上次运行阶段保留在「反馈 → 故障记录」供手动查看，不再自动弹出。
- 真正的新崩溃、启动失败仍会保留故障记录与恢复保护。

## 验证与范围

发布要求单元测试、Lint、原生回归与 Android 5.0、5.1、6.0、12 模拟器检查通过。新增测试检查断开与更换状态流的每一帧、视频播放器反复解绑和重新绑定，以及跨进程保留崩溃编号、时间与重试确认。

模拟器回归覆盖已定位的故障路径，索尼电视上的待机与开机体验仍需实机确认。
